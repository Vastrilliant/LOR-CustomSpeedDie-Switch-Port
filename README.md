# Requirements 
A modded Nintendo Switch with Atmosphère or an Emulator that supports Atmosphère mods 

# How 2 use 
Download **SpeedDiceColor_romfs.zip** and **subsdk9** in [releases](https://github.com/Vastrilliant/LOR-CustomSpeedDie-Switch-Port/releases/)

Put **subsdk9** in `sdcard/atmosphere/contents/0100E7A019246000/exefs/`

Unzip and put the contents of **SpeedDiceColor_romfs.zip** in `sdcard/atmosphere/contents/0100E7A019246000/`

>[!WARNING]
>This only works on the latest update (1.0.3), it won’t work on the base 1.0.0 version (why would you use that anyway)
